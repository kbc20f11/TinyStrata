# Measured speed — AMD Radeon RX 9070 XT (HIP)

Measured on **2026-11-12** using Windows 11 (build 26300), a Radeon RX 9070 XT (gfx1201, 16 GB; driver 32.0.32015.7029), a Ryzen 9 7945HX3D and 96 GB of system RAM, with the same model files as in the main [README](../../README.md). INT8 KV and VMM growth were enabled; the growable KV used the verified 64 KiB allocation quantum (`hip_vmm_verified=1`, `hip_vmm_quantum_kib=64`). Context capacity, input chunks and Expert placement were automatic. Qwen and Gemma used MTP 3 and a GPU-resident image encoder; LFM and the standard Clover row use neither.

Protocol: [tinystrata-bench-v1](../README.md#english), engine code [73167a6](https://github.com/kbc20f11/TinyStrata/commit/73167a6f549aac65995afbddb353a446cfa00e30) (clean `origin/main`), seed 1234, four independent API starts per model. The engines were built with `install.ps1 -Backend hip -HipArchitectures gfx1201 -Rebuild` against the installer's private ROCm SDK (10.2.0a20260930); the HIP runtime beside the executables is `amdhip64_7.dll` 10.0.3686.0. The previous run on this page, from 2026-11-04, used engine code [358043c](https://github.com/kbc20f11/TinyStrata/commit/358043c3749f5c6da36c749c98201c82b9c57a72) and the runtime installed with the display driver; it is kept [below](#earlier-run-2026-11-04-358043c).

The standard run was made 12 minutes, and the saved-profile run 28 minutes, after a Windows restart (see [Measurement conditions](#measurement-conditions)).

## Measurement conditions

- Restart at 17:36; standard v1 started at 17:48 and the saved-profile run at 18:04. A short wait for CPU idleness was skipped, so CPU use before the run was not recorded; it measured 6–9% a few minutes earlier. About 1.76 GiB of VRAM was in use before the run. Discord and LM Studio were running and Task Manager was closed.
- Windows power plan: Balanced. Discord and the browser were assigned to the integrated GPU in the Windows graphics settings. Both monitors were connected to the RX 9070 XT, as checked on 2026-11-11 (issue #1); this was not re-checked after the restart.
- Executables (SHA-256): `tinystrata.exe` (Qwen, Tiel Coder) `b67d2dba…7a84`, `tinystrata.exe` (Clover) `eed2d822…2ad8`, `tinystrata-gemma4.exe` `913df1a1…33db`, `tinystrata-lfm2.exe` `5f6e9d06…5ceb`; benchmark runner `1965e021d8f0bef6696cd3145e6349968a159a7c607be09638561dc3288d81b2`, cases `aa49a073…eabde`, image `b6983fe5…3138`. The models and inputs are the same files as in the earlier runs.
- Speed on this PC also depends on the state of the Windows session (see issue #7 and the [2026-11-04 notes](#earlier-run-2026-11-04-358043c) below); record the time since the last restart with any figure you compare.
