# Measured speed — AMD Radeon RX 9070 XT (HIP)

Measured on **2026-10-28** using Windows 11, a Radeon RX 9070 XT (gfx1201, 16 GB; driver 32.0.31041.3013), a Ryzen 9 7945HX3D and 96 GB of system RAM, with the same three model files as in the main [README](../../README.md). INT8 KV and VMM growth with a 4 MiB allocation quantum were enabled. Context capacity, input chunks and Expert placement were automatic. Qwen and Gemma used MTP 3 and a GPU-resident image encoder; LFM used neither.

Protocol: [tinystrata-bench-v1](../README.md#english), engine code [bc0aba1](https://github.com/kbc20f11/TinyStrata/commit/bc0aba1), seed 1234, four independent API starts per model.

| Model | Context capacity | Generation (tok/s) | 4K input (tok/s) | 16K input (tok/s) | Image first / end (s) | Notes |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Qwen3.6 UD-IQ3_XXS | 256K | 97.89 | 1353.97 | 1561.60 | 1.94 / 3.95 | Expert cache 7.44 → 7.22 GiB |
| Gemma 4 QAT Q4_0 | 256K | 70.40 | 2697.67 | 3589.72 | 1.03 / 1.98 | Expert cache 7.81 → 7.62–7.69 GiB |
| LFM2.5 Q4_K_M | 128K | 88.99 | 1749.32 | 1880.91 | — | Expert cache 11.87 → 11.75 GiB |

Image times show first output / response end, including image encoding; lower is faster. Expert cache values show the actual allocation at startup → immediately after the 16K input, in GiB.

Background apps matter on this card. While Discord drew on the discrete GPU, other apps held about 5.4 GiB of VRAM and Qwen measured 71.87 generation / 623.64 4K / 745.72 16K tok/s with a 4.19 GiB Expert cache. The table above was taken after assigning Discord to the integrated Radeon in the Windows graphics settings, which left about 1.8 GiB in use. The runner does not record other apps' VRAM use.
