# GeForce RTX 3060 12 GB · Inkling 2 Mini branch benchmark

Measured on 2026-11-25 with Windows, GeForce RTX 3060 12 GB (sm_86, driver 610.88), Ryzen 9 7945HX3D, and CUDA 13.2.86. TinyStrata [69d7b53](https://github.com/kbc20f11/TinyStrata/commit/69d7b5345ceb0e7fc21fdd87340c3184084bb9b9) uses the pinned Unsloth UD-IQ4_XS weights and native Strata Vision shard.

Protocol `tinystrata-bench-v2-inkling` completed four independent starts. Each start ran the three generation prompts twice, the exact 4,096- and 16,384-token inputs, and the canonical cold image. Seed 1234, automatic chunks, thinking enabled for text, and drafting off were used. The runner marks this Inkling extension `standard: false` because it uses automatic KV and the in-process Vision encoder. The CUDA image timing includes CPU encoding.

| Model | Generation tok/s | 4K input tok/s | 16K input tok/s | Image first output / complete (s) | GPU Experts |
|---|---:|---:|---:|---:|---:|
| Inkling 2 Mini UD-IQ4_XS | 34.89 | 380.17 | 367.83 | 25.22 / 28.47 | 624 / 3,072 |

Text rates pool native token counts and times. Image times are medians across the four starts and include encoding. Startup is excluded. The chosen context was 131,072 tokens, with 4,096 MiB of global device KV in FP16.

The TinyStrata launch passed one slot, `--kv auto`, and `--kv-gpu-first`. This retained the native CUDA engine's FP16 default at the measured revision. The inherited auto-format rule selects FP8 with 16 or more parallel slots or with explicitly disabled KV offload on qualifying GPUs. The GPU-first option allocates capacity on-device and is independent of that format selector.
